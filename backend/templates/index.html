SOBRE

O chat FAROL permite conversar com uma IA capaz de responder perguntas e analisar contextos.

Construído para operar de forma totalmente local, o sistema garante a privacidade e a autonomia no processamento de informações.

  • Use o Chat Normal (padrão) para perguntas gerais.
  • Use o RAG para consultar documentos enviados.
  • Use o Web Search para buscar informações na internet.
  • Use o Cloud AI para usar modelos externos (GPT, Gemini).

Configure suas chaves de API em ⚙ Configurações para usar modelos cloud.
